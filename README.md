# EstequioLab

Laboratorio virtual 3D para comprender y practicar el balance de ecuaciones químicas en procesos agroindustriales (Ingeniería Agroindustrial, Universidad Surcolombiana).

## Publicar en GitHub Pages
1. Crea un repositorio (por ejemplo `estequiolab`) y sube el contenido de esta carpeta a la raíz.
2. Settings → Pages → Branch `main`, carpeta `/ (root)`.
3. Abre `https://<usuario>.github.io/estequiolab/` y usa «Instalar aplicación» del navegador.

Funciona sin conexión después de la primera visita (service worker en `sw.js`). Para publicar cambios, sube la versión de `CACHE` en `sw.js`.

Datos termodinámicos: ΔH°f a 298,15 K (NIST Chemistry WebBook, doi:10.18434/T4D303; CRC Handbook of Chemistry and Physics).
